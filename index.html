01

Aplikasi Web

Surat digital

Warkah

Tulis surat yang hanya bisa dibuka di tanggal tertentu. Bagikan link-nya, penerima melihat hitung mundur sampai waktunya tiba. Tanpa server, data tersimpan di link itu sendiri.

buka Editor visual

Retouch

Tempel HTML hasil ChatGPT/Claude, edit langsung secara visual (drag, ganti teks, gambar), lalu ekspor HTML bersih.

buka Form builder

Formie

Rakit formulir HTML dengan drag and drop, ekspor jadi file siap pakai.

buka Desain

Thema

Upload gambar, dapatkan tema warna lengkap: CSS variables, Tailwind, shadcn/ui.

buka Data

CrispData

Bersihkan dan konversi data berantakan: Markdown, JSON, CSV, tabel HTML.

buka Utilitas

DevToolKit Pro

12 alat developer dalam satu halaman: JSON formatter, regex tester, hash, JWT, diff, dan lainnya.

buka Permainan

Kata Kilat

Tebak kata Bahasa Indonesia dari definisi KBBI. Cepat, seru, langsung main.

buka Keuangan

Penghitung Kurs

Konversi 22 mata uang dengan kurs live. Antarmuka Bahasa Indonesia.
