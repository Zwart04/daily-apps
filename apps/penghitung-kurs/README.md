# Penghitung Kurs

**Konversi mata uang secara real-time. Gratis, tanpa daftar, langsung di browser.**

Penghitung Kurs adalah alat bantu untuk konversi mata uang yang bisa dipakai langsung dari browser HP atau komputer. Cocok untuk siapa saja yang perlu tahu nilai tukar Rupiah ke Dollar, Ringgit, Dolar Singapura, Euro, Yen, dan puluhan mata uang lainnya — baik untuk belanja online, perjalanan ke luar negeri, kirim uang, atau cek harga dari toko luar negeri.

## Features

- **Konversi 22 mata uang dunia** — IDR, USD, SGD, MYR, EUR, JPY, GBP, AUD, CNY, KRW, THB, PHP, SAR, AED, HKD, INR, BND, VND, TWD, CHF, NZD, CAD
- **Kurs live dari Open Exchange Rates** — diperbarui otomatis setiap buka halaman
- **Tombol pasangan populer** — langsung pilih IDR ke USD, SGD ke IDR, dll.
- **Jumlah cepat** — 1, 10, 100, 1.000, 10.000, 100.000, 1 Juta
- **Tukar arah** — satu klik untuk membalik mata uang asal dan tujuan
- **Mode offline** — pakai kurs yang terakhir tersimpan walau tanpa internet
- **Privasi penuh** — semua data diproses di browser kamu, tidak dikirim ke server
- **Bisa dipasang di HP** — buka di Chrome, pilih "Add to Home Screen"

## Cara Pakai

### Buka di Browser

1. Buka alamat: **http://apps.zwart.qzz.io/20260707-penghitung-kurs/**
2. Masukkan jumlah uang
3. Pilih mata uang asal dan tujuan
4. Hasil konversi muncul otomatis

Atau buka langsung file `index.html` dari komputer / HP.

### Dari HP (Android / iOS)

1. Buka link di Chrome / Safari
2. Pilih menu "Add to Home Screen" atau "Pasang Aplikasi"
3. Penghitung Kurs siap dipakai seperti aplikasi biasa

## Fitur

| Fitur | Keterangan |
|-------|-----------|

## Kenapa Berguna

Setiap hari, banyak orang Indonesia yang:
- Belanja di marketplace luar negeri (Amazon, AliExpress, Shopee cross-border)
- Travel / umroh / kuliah di luar negeri
- Kirim uang ke keluarga di luar negeri
- Jual produk ke pembeli luar negeri
- Cek harga saham / crypto yang pakai Dollar

Penghitung Kurs membantu mereka semua dapat informasi kurs dengan cepat, tanpa harus buka Google atau aplikasi bank.

## Tech

- HTML + CSS + JavaScript murni (1 file)
- Tailwind CSS via CDN
- Open Exchange Rates API
- LocalStorage untuk cache kurs
- Berat: ~28KB
